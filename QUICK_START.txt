# Quick start — HDD Unmess

1. Install Python 3.10+ from https://www.python.org/downloads/windows/
   During setup, tick **Add python.exe to PATH**.
2. Install Visual Studio Code and the Microsoft Python extension.
3. Extract this project to:
   `C:\_MyDocs\_LCourses\_DS5\y04-hdd-unmess`
4. In VS Code, select **File > Open Folder...** and open that folder.
5. Open **Terminal > New Terminal**.
6. Check Python:
   `py --version`
7. Run the app:
   `py app.py`
8. In the menu, enter `1` to analyse a folder/drive, or `2` to review drive space.
9. Choose a recommendation number. The app opens the relevant location or asks for confirmation before cleanup/moving.
10. Press `0` at menus to return/exit.

No `pip install` is needed.

Tip: first run the app in scan/review mode. Do not move or delete files you do not recognise. Back up important files first.
